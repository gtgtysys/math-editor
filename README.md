# Ceol Formula Studio

PowerPoint向けの、ブラウザで使う数式エディタです。フォントファイルは同梱しません。PCにインストールされたTTF／OTFを一覧から選べます。Ceol Italicがあれば初期フォントに使い、なければTimes New Romanなどで起動します。数式記号はすべてEuclid Symbol（通常版がなければBold）を優先します。未収録の記号だけEuclidなどで補います。Euclid系がない場合はTimes New Romanなどで代用し、文字ごとの指定は常に優先します。

## ブラウザで使う（推奨）

[エディタを開く](https://gtgtysys.github.io/math-editor/)。ダウンロード・Node.js・ローカルサーバーの起動は不要です。

初回は「PCのフォントを使う」で利用を許可するか、「フォントを追加」でTTF／OTFを選択します。PCフォントへのアクセスは対応するデスクトップChromiumブラウザで利用できます。ファイルから追加したフォントはこのブラウザのIndexedDBに保存されます。サイトデータを削除すると再追加が必要です。フォントはアップロードしません。

画像コピーはPNGが初期設定です。ベクター画像はSVG保存後にPowerPointへ挿入できます。ブラウザ版ではPPT経由のクリップボードに編集情報が残る保証はありません。再編集にはアプリで保存したSVG・PNG・JSONを使ってください。AIキーはタブ内だけで保持します。

## Windowsローカル版（高度なPPTクリップボード連携用）

1. [リポジトリのCode → Download ZIP](https://github.com/gtgtysys/math-editor/archive/refs/heads/main.zip) からダウンロードし、ZIPを「すべて展開」します。
2. [Node.js](https://nodejs.org/)のLTS版をインストールします（初回のみ）。
3. 展開したフォルダーの `Start-Editor.cmd` をダブルクリックします。ブラウザが自動で開きます。
4. 作業中は起動したウィンドウを開いたままにしてください。終了はそのウィンドウでCtrl+Cです。

通常の利用にGit、npm install、APIキーは不要です。AIによる画像認識・自然言語入力を使うときだけ、ご自身のAPIキーを設定します。ダウンロード版の必要環境はWindows 10/11、Node.js 22以上、Windows PowerShellです。

開発環境を作り直す場合のみ `npm install` と `npm run build` が必要です。WindowsのローカルサーバーがPCフォントの読み込みとSVG／EMFクリップボードを担当します。静的配信ではブラウザのフォント機能と画像クリップボードを使います。Times New Romanは配布物にコピーしません。

## 操作

1. 左の数式欄に入力するか、分数・平方根などのボタンでパーツを追加します。
2. キャンバスの文字をクリックすると書き換えられます。Shiftクリック、Ctrlクリック、空白からのドラッグで複数パーツを選択できます。ドラッグ、X/Y指定、矢印キーでまとめて位置調整できます。分数線や根号も選択できます。
3. 入力欄またはキャンバスで数値を選び、平方根・上付き・下付きボタンを押すと選択範囲に適用します。たとえば `x25` の `25` を選んで上付きを押すと `x^{25}` になります。記号ボタンは選択範囲の後に追加します。
4. 色はPowerPoint標準色と無彩色から選びます。選択範囲だけの色変更も可能です。出力サイズは初期値1/3で、等倍にも戻せます。
5. 「画像をコピー」は初期設定でベクター（SVG／EMF）をコピーします。通常の貼り付けでSVGグラフィックスとして使用できます。PNGへの切り替え、SVG保存も可能です。「PPTから貼り付け」はWindowsの画像クリップボードを読み込みます。
6. このアプリが保存したPNG・SVG・JSONを「読み込む」で開くと、数式と文字ごとの調整を復元できます。キャンバスへのドロップもできます。

## AI設定

「AI設定」でGoogle AI Studio (Gemini) またはOpenAI、利用可能なモデル名、APIキーを入力します。プロバイダーを切り替えればアプリの変更は不要です。モデル名は自身のAPIアカウントで利用できるものを指定してください。

自然言語を入力して「数式に変換」を押すと数式になります。通常のPNG/JPEG/WebPは「読み込む」、ドラッグ＆ドロップ、画像貼り付けで添付してから同じボタンで認識します。AIの出力は適用前に数式構文を検証しますが、数学的な読み取りの正しさは確認してください。

キーはタブ内のメモリだけに保持し、ファイルやブラウザストレージに保存しません。公式APIへブラウザから直接送信する個人用構成です。複数ユーザー向けに公開し共通キーを配布する場合は、サーバー側の認証・APIプロキシに移行してください。APIを呼び出すのは「数式に変換」を押した時だけです。

公式仕様： [Gemini generateContent](https://ai.google.dev/api/generate-content)、[OpenAI Responsesの画像入力](https://developers.openai.com/api/docs/guides/images-vision)。実APIの課金を伴う接続テストにはユーザー自身のキーが必要です。

## 対応範囲と制約

- 新しい数式は組版v2を使用します。TeXの数式アトム（通常文字・二項演算子・関係記号・括弧・句読点・関数など）による3/4/5muの間隔、単項符号の判定、添字内の間隔抑制、フォントのカーニング、字形の実寸に基づく指数・添字配置に対応します。分数線・大型演算子の中心は使用フォントの等号の中心に合わせます。
- 配置規則の参考：[KaTeXの数式間隔](https://github.com/KaTeX/KaTeX/blob/main/src/spacingData.ts)、[TeXの添字配置規則を実装したKaTeX](https://github.com/KaTeX/KaTeX/blob/main/src/functions/supsub.ts)。TeXエンジン自体やOpenType MATHテーブルを使うものではなく、任意のフォントの実寸に適応する近似実装です。字形固有のMathKern・合字・伸縮括弧には未対応です。
- 旧版の保存ファイルは旧配置のまま復元します。本文を編集すると新しい組版に切り替わります。新しく保存する画像・JSONには組版バージョンも記録します。
- 手動の空き調整には `\,`（3mu）、`\:`（4mu）、`\;`（5mu）、`\!`（−3mu）、`\quad`（1em）も使えます。キャンバス上の文字移動も引き続き使用できます。

- 分数、平方根・n乗根、上付き・下付き、総和、積、積分、アクセント、ギリシャ文字、基本的な関数、最大12×12の行列に対応します。完全なTeXエンジンではありません。未対応コマンドはエラー表示します。
- 選択フォントにない文字は、利用可能ならPC内の小塚明朝などで補います。それでもない文字は、対応するフォントを追加してください。フォント自体にない字形を生成することはできません。
- SVGの文字はパス化します。PNGは透過対応、PNGのiTXtチャンクおよびSVGのmetadataに構成データを埋め込みます。外部SVGのスクリプト・画像・スタイルは実行せず、アプリ用metadataだけを取り出します。
- ブラウザのクリップボードやPowerPoint・画像編集ソフトによる再保存では編集情報が失われることがあります。確実な再編集には、アプリから保存した元のPNG/SVGまたはJSONを残してください。
- Windowsのコピーには専用編集データとEMFコメントにも構成情報を入れます。さらに直近30件の出力画像と編集データの対応をブラウザに保存し、メタデータが除去されても画素が完全一致するPNGなら復元を試みます。拡縮や再描画で画素が変わった画像の完全復元は保証しません。
- SVGはptで物理サイズを指定、PNGは96dpi×解像度倍率のpHYsを付加します。貼り付け先が解像度情報を無視する場合、サイズの自動統一は保証できません。PowerPoint実機での表示サイズは別途確認が必要です。
- PowerPointには画像として入ります。PowerPointのネイティブ数式としては編集できません。このエディタに読み戻して編集します。
- 追加フォントはタブ内だけに読み込みます。そのフォントを用いたデータの再編集時には同じフォントを追加してください。パス化したSVGとPNGの表示には元のフォントは不要です。
- 文字や記号を追加しても、変更していない文字・数式の線の位置調整と色は引き継ぎます。削除・置換した文字の調整は解除します。元に戻す操作で回復できます。未保存の数式・追加フォント・API設定はタブ再読み込みで消えます。

## 構成・検証

- `dist/engine.js`: 数式の構造・字形パス・配置
- `dist/app.js`: 編集、履歴、画像入出力
- `dist/png.js`: PNG構成データと物理サイズ
- `dist/providers.js`: Gemini / OpenAI切り替え
- `dist/editing.js`: 選択範囲操作・色・クリップボード形式
- `server-native.mjs`: ローカルサーバー、フォント・クリップボードAPI（127.0.0.1のみ、同一Origin限定）
- `scripts/ClipboardBridge.cs`: WindowsのEMF生成と画像クリップボード入出力
- `npm test`: 実フォント描画、位置調整の復元、PNGチャンクの往復、異常データ拒否、API要求の検証

フォントはWindowsのシステム／ユーザーフォントフォルダーから読み込みます。TTCコレクション、カラー絵文字など、一部のフォント形式には対応していません。新しくインストールしたフォントはサーバーを再起動すると一覧に反映されます。追加フォントや字体の再現には利用するPCにも同じフォントが必要です。opentype.jsのライセンスは `dist/vendor/opentype-LICENSE.txt` にあります。

## PowerPoint往復の実機検証（2026-09-23）

PowerPointはSVGのmetadataを除去するため、描画面積ゼロ・線なしのベクターパスにも編集データを記録します。再コピー時はWindowsのSVG形式から直接復元します。APIやコピー履歴は不要です。PowerPointで貼り付け・再コピー・幅変更後の再コピーを実機確認し、数式、18pxの移動量、色の復元を検証しました。実際のPPT出力を回帰テストに含めています。

修正前に出力した画像には新しい復元情報がありません。新しい版からコピーし直してください。PNGへの変換・スクリーンショット・図形への分解などでベクター情報を失った場合は対象外です。PPT上の画像拡大率ではなく、エディタで設定したフォントサイズ・位置を復元します。


## 開発と公開

`npm ci` → `npm run build` → `npm test` で検証できます。テストはCeol等が手元になければ独自の幾何学字形を生成して実行するため、フォントファイルなしで動作します。`dist/vendor`にはブラウザ用ライブラリを含めているので、ダウンロードしたアプリはnpmによる準備なしで起動します。既存の `math-editor/` フォルダーは以前のReactテンプレートです。今回のWindows版はリポジトリ直下から起動してください。

根号を自分で調整する場合は [編集用SVG](dist/design/radical-template.svg) をInkscapeで開いてください。[編集手順](dist/design/README.md) にパスと寸法の説明があります。

## ローカルサーバーの終了条件

ブラウザのタブを閉じても終了しません。起動コンソールのCtrl+C、コンソールを閉じる、サーバープロセスの終了、Windowsのサインアウト／再起動／シャットダウンで停止します。アイドル時間による自動停止はありません。スリープは終了ではなく一時停止です。公開ブラウザ版の利用にローカルサーバーは不要です。
