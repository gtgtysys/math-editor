# 根号をInkscapeで編集する

`radical-template.svg` を開き、ノードツール（N）で黒い線を調整してください。

- `radical-hook`：根号の左側。自由にノードや曲線を編集できます。
- `radical-overbar`：数式の上に伸びる横線。独立したパスです。
- 単位は1em＝100。現在の線幅は4、下端はy=0、上線はy=-82です。
- 「ガイド」レイヤーは初期状態では非表示です。必要なら表示できます。

編集後はPNGではなくSVGで保存して、この会話に渡してください。グループやパス名を保っていただけると組み込みやすくなりますが、変更しても対応できます。アプリへの組み込み時に、分数を囲む背の高い根号・長い上線にも合うよう伸縮方法を調整します。現時点ではこのSVGを読み込んでもアプリの根号設定は変わりません。
